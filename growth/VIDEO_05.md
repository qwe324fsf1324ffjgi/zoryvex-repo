# VIDEO 05 — "We deleted the upload button"

**The counterintuitive one.** Highest share potential in the set, because it
is a company removing a feature and explaining why.

- **Length:** 28s · **Format:** screen recording + voice · **One idea:** a file you uploaded proves nothing
- **Claimable:** yes — this is a recorded product decision

## Hook — second zero

A file picker dialog opening. Then, immediately, it closes and the control
disappears from the page.

Caption: **"We removed this on purpose."**

## Script

> "We used to let you upload a file as proof. A certificate PDF, a screenshot,
> a report.
>
> We removed it.
>
> Here's why. A file you upload is a file you control. You made it, or you
> could have. Checking it tells us the file exists. It doesn't tell us the
> thing in it is true.
>
> That's not proof. It's a claim with a nicer font.
>
> What's left is what we can check against something you don't control: a
> certificate confirmed with the body that issued it, and a repository you
> prove you control with a one-time code in a public gist.
>
> Fewer ways to add evidence. Every one of them means something."

## Why this spreads

Companies add features and announce them. A company subtracting one, and
giving a reason that survives scrutiny, is unusual enough to be worth sending
to someone. The argument is also short enough to be repeated accurately by
whoever shares it, which is what actually makes something travel.

## Do not

Do not frame it as "competitors accept uploads and they're wrong." Make the
argument about the evidence, not about other companies.
