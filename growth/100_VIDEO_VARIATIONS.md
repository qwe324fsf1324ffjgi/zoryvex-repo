# 100 video variations

Ten core ideas, ten angles each. Every line is a **hook** — the first thing on
screen at second zero — plus the shift the video makes after it.

Rules that apply to all 100, without exception:

- The hook is the first frame, not an introduction to the first frame
- One idea per video. If a hook needs two, it is two videos
- Nothing here may claim a customer, an outcome, or a statistic about Zoryvex
- Captions burned in. Assume silence
- Green appears once, at verification, or not at all

Numbers in brackets are the core script the variation belongs to.

---

## 1–10 · The claim/source contrast [VIDEO 01]

1. **"Watch me lie on a CV."** — type it, then run the check. *(the original)*
2. **"I'm going to add a certification I don't have."** — the check refuses it.
3. **"This took four seconds to write."** — cut to the twenty-second check that settles it.
4. **"Nobody has ever checked this line."** — pointing at a CV bullet. Then somebody does.
5. **"Two candidates. Same claim."** — one verified, one not. Same words on the page.
6. **"What's the difference between these two lines?"** — visually identical, one checked.
7. **"I could write 'CEO' here and the file wouldn't argue."** — then a source that would.
8. **"The word 'certified' is doing a lot of work here."** — then show what confirms it.
9. **"A CV is a claim."** — three-second pause on black. "A source is a source."
10. **"You don't need a better CV. You need one somebody checked."**

## How to actually use this list

**Do not shoot 100 videos.** Shoot the ten core scripts. Publish them.
Measure 3-second retention and saves, not views.

Then take the **two** that held attention and shoot their nine variations
each. That is roughly 28 videos from an evidenced starting point instead of
100 from a guess.

A variation that repeats a hook which already failed is not a second attempt.
It is the same attempt.

## The ten that should never be shot

If a hook ever drifts into one of these, delete it:

- Any percentage about Nigerian CVs, candidates, or hiring
- Any Zoryvex customer, outcome, hire, or time-saved figure
- "Trusted by", "used by", "join thousands"
- Any named competitor
- Any real person's evidence, real or invented
- Anything implying most candidates lie
- Any price without the exact Paystack disclosure in the same frame
- Any claim that Zoryvex prevents identity fraud
- Any "wait for it", countdown, or manufactured cliffhanger
- Anything a viewer would feel slightly worse for having watched
